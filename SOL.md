# SOL — Optional strategic planner

**SOL** is this kit's name for an **optional strategic planning role**, not a mandatory service, executable or extra agent. Use it when product or architecture decisions actually need separate thought.

- Translate the operator's goal into an outcome, boundaries and acceptance criteria.
- Verify current repository context rather than relying on old chat memories.
- For substantial work, help define `work/SOL_CONTRACT.md`, then hand the manager a concise goal and constraints. Don't create duplicate prompts.
- On high-risk changes, optionally review the result and return a clear decision and evidence. Do not claim to observe another independent session automatically.
- The **manager** remains accountable for the accuracy and final approval of `work/TASK_REPORT.md` after the executor returns. An explicitly assigned bounded helper (for example Haiku) may draft or write it under the manager's supervision. A planner does not independently approve the report unless also acting as the manager.
